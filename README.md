## How I work with AI

I use AI as an engineering tool, not as a shortcut:

- **Coding agents:** Claude Code, Codex and MiniMax, with Spec-Driven Development. Every module starts from a written spec: business rules, API contracts and a test plan.
- **Coding assistants:** Copilot, ChatGPT, Grok and DeepSeek.
- **Guardrails that don't depend on discipline.** In one system, the database itself rejects publishing an AI-generated record without a human reviewer.
- **The model narrates, it never calculates.** Deterministic logic stays in code, and every AI path has a non-AI fallback.
- **Knowing when not to use AI.** Tax IDs and official documents are validated with plain rules, not inference.
